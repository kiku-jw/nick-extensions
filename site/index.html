Feature settings

What you can do

Six useful jobs, explained plainly

Each tool appears only where it has something useful to work with.

01

Keep a place for later

Save the exact paragraph or verse you want to revisit for a meeting, talk, or personal study—not just the top of the page.

Use it when:you found something useful but cannot study it now.
02

Send a quote that makes sense

Copy the selected words, their reference, and a precise link in one action. It is ready to paste into a message or notes.

Use it when:you want the reader to see both the quote and its source.
03

Link several verses

Click the first verse number, then Shift-click the last. Copy one link for the whole consecutive range.

Use it when:one thought continues through verses 3–5.
04

Get a stable publication link

StudyNav uses the current publication data to open a clean Finder address that is easier to save or share.

Use it when:the visible page address is long or contains extra parameters.
05

Download only what you need

Save one narrated verse, or enter start and end times to export audio as WAV or video as WebM. No manual trimming afterward.

Use it when:you need a short excerpt for rehearsal, offline listening, or playback.
06

Keep notes beside the text

Six Library-like colors, notes, and tags are stored locally. On wide screens, notes appear in a right rail; on narrow screens, a Notes button opens them.

Use it when:you want the note visible without moving or covering the article.

Installation

From download to working extension

No repository, terminal, build tools, or commands are required.

  1. Download the ZIPPress the button and save the archive.
  2. Unzip itOpen the downloaded file once. A studynav-1.5.0 folder appears.
  3. Open chrome://extensionsPaste that address into the browser address bar.
  4. Turn on Developer modeUse the switch in the upper-right corner.
  5. Press Load unpackedChoose the unzipped folder. Then pin StudyNav from the puzzle-piece menu.

Questions

Before you install or share it

Short answers to the questions that are likely to come up.

Which browsers are supported?

Current Chromium browsers: Google Chrome, Microsoft Edge, and compatible Chromium builds. Firefox and Safari are not packaged or tested.

Should this go into the Chrome Web Store?

Start with a small friends-only or unlisted beta. Fix compatibility reports, prepare a privacy policy, and ask JW.org support whether the name and public distribution create concerns before a broad store launch. StudyNav must never imply official endorsement.

Is the publication search powered by AI?

No. It expands known publication codes and document IDs into the existing JW.org/WOL searches. Adding Gemini would require sending queries to another service, managing credentials and privacy, and still would not guarantee better results.

How do I link verses 3 through 5?

Click verse 3, then Shift-click verse 5. StudyNav selects the consecutive range; Copy gives clean verse text, and Link gives one address ending in #v…-v….

What does “clean text” remove?

Verse numbers, reference letters, footnote links, and StudyNav labels or buttons. It keeps the actual words of the selected verse or paragraph.

Why can a selection contain up to 10,000 characters?

The earlier 2,000-character cap was unnecessarily restrictive. The 10,000-character bound supports longer excerpts while still preventing accidental whole-page capture and oversized local records.

Why do some options show no change on the homepage?

Article image buttons, the sticky article header, wider reading pane, and clearer tables require a detected article structure. The JW.org homepage does not use that structure. WOL intentionally receives notes and study tools but not layout overrides.

Why is the captions button sometimes absent?

StudyNav only shows it when the page exposes caption tracks or transcript text. It does not invent a transcript and does not send audio to a transcription service.

Does one-verse audio work in Russian and Ukrainian?

Yes, for supported Bible chapter pages using the confirmed JW language codes. If the page has not loaded chapter media yet, start Play Audio once and try again.

Why are clips WAV and WebM?

The browser can create both formats locally without adding a large codec. Audio is limited to two minutes in WAV; video is recorded in real time for up to one minute in WebM. The source must be a JW CDN media file.

Why was Download article images still on in my profile?

Older saved settings can outlive new defaults. New installs start with it off. Press Reset recommended defaults in the popup to apply the current defaults to an existing profile.

Can notes synchronize between devices?

There is no remote sync. Export the Study library JSON from one browser profile and import it into another. Import merges valid records and does not delete existing ones.

Why not use screenshots from real publications everywhere?

A private demonstration can show the live site while explaining the extension. A public guide is more cautious: JW.org’s terms restrict republishing its artwork, publications, and media. The guide therefore demonstrates extension behavior without bundling official publication content.

Product choices

Added where the browser has a clear gap

StudyNav borrows useful ideas from JW Library—bookmarks, colored highlights, notes, and trimming—without adding accounts, passive history, feeds, or an AI service.

Added

Six-color notes rail, exact saved places, verse ranges, one-verse audio, time-bounded audio and video clips, player shading removal, reliable focused-player keys, and an explicit image-search shortcut.

Not added

Remote/community notes, passive browsing history, feeds, bulk media download, AI search, and a general video editor. They add permissions or data handling without a strong in-page study benefit.
