Feature settings

What you can do

Use StudyNav for these six tasks

The controls appear on the JW.org pages where they work.

01

Keep a place for later

Save the exact paragraph or verse you want to revisit for a meeting, talk, or personal study—not just the top of the page.

Use it when:you found something useful but cannot study it now.
02

Send a quote with its source

Copy the selected words, their reference, and a precise link in one action. It is ready to paste into a message or notes.

Use it when:you want the reader to see both the quote and its source.
03

Use several verses together

Select the first verse, choose Select several, then select the last. Copy the text, copy one link, or download the range as one audio file.

Use it when:one thought continues through verses 3–5.
04

Get a shorter publication link

StudyNav opens the same publication through a JW.org address without the extra technical parts.

Use it when:you want a simple address to save or send.
05

Download only what you need

Save the narration of one verse or several consecutive verses. For other media, enter start and end times to save a short WAV or WebM clip.

Use it when:you need a short excerpt without trimming the full file yourself.
06

Keep notes beside the text

Six Library-like colors, notes, and tags are stored locally. On wide screens, notes appear in a right rail; on narrow screens, a Notes button opens them.

Use it when:you want the note visible without moving or covering the article.

Installation

From download to working extension

You only need the downloaded archive and your browser's extensions page.

  1. Download the ZIPPress the button and save the archive.
  2. Unzip itOpen the downloaded file once. A studynav-1.5.1 folder appears.
  3. Open chrome://extensionsPaste that address into the browser address bar.
  4. Turn on Developer modeUse the switch in the upper-right corner.
  5. Press Load unpackedChoose the unzipped folder. Then pin StudyNav from the puzzle-piece menu.

Data

What stays local—and what opens externally

Stored in the browser

  • Highlights, selected quotes, notes, and tags
  • Saved page, paragraph, verse, and range links
  • Where you stopped in recently watched media
  • A backup file you can export and import

Requested only after an action

  • Official JW audio or video needed for the clip you chose
  • An article image after Download image
  • Google image search after you submit a query
  • No account, analytics, or remote note sync

Questions

Answers before you install

Compatibility, audio, notes, links, and common limitations.

Which browsers are supported?

Current desktop Chromium browsers: Google Chrome, Microsoft Edge, and compatible Chromium builds. Firefox and Safari are not supported.

Is StudyNav an official JW.org extension?

No. It is an independent open-source project and is not produced, endorsed, or maintained by Jehovah’s Witnesses.

Is the publication search powered by AI?

No. It is for cases where you already know a publication code or document number, and opens the regular JW.org/WOL search for it. It does not search by the meaning of the text.

How do I select verses 3 through 5?

Select verse 3, choose Select several, then select verse 5. Copy uses all three verses, Link creates one direct address, and Download audio saves the range as one WAV file. Shift-click still works as a keyboard shortcut.

What does “clean text” remove?

Verse numbers, reference letters, footnote links, and StudyNav labels or buttons. It keeps the actual words of the selected verse or paragraph.

How much text can I highlight?

Up to 10,000 characters in one saved highlight. This is enough for a long excerpt while preventing an accidental whole-page selection from becoming one oversized note.

Why do some options show no change on the homepage?

Image buttons, scrolling navigation, the wider column, and table styling work inside articles. The homepage has no article column or table for them to change. Notes still work in WOL, but the three article-appearance changes do not run there.

Why is the captions button sometimes absent?

StudyNav only shows it when the page provides subtitles or transcript text. It does not invent a transcript and does not send audio to a transcription service.

Does verse audio work in Russian and Ukrainian?

Yes. On supported English, Russian, and Ukrainian Bible chapter pages, you can download one verse or several consecutive verses. If the chapter media has not loaded yet, start Play Audio once and try again.

Why are clips saved as WAV and WebM?

The browser can create these formats without sending the media to a server. You can save up to two minutes of audio as WAV or one minute of video as WebM.

Why was Download article images still on in my profile?

Older saved settings can outlive new defaults. New installs start with it off. Press Reset recommended defaults in the popup to apply the current defaults to an existing profile.

Can notes synchronize between devices?

There is no remote sync. Export the Study library JSON from one browser profile and import it into another. Import merges valid records and does not delete existing ones.

Can I use StudyNav on a smartphone?

No. Mobile Chrome does not support desktop extensions, so StudyNav buttons will not appear on a phone. Links you create on a computer still open on a phone as regular JW.org links.

StudyNav is an independent, unofficial open-source project. It is not produced, endorsed, or maintained by Jehovah’s Witnesses. JW.org and JW Library are named only to explain compatibility.
