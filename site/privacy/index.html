Privacy

StudyNav privacy policy

Effective August 24, 2026. StudyNav is published by KikuAI Lab as an independent, unofficial open-source project.

The short version

StudyNav has no user account, analytics, advertising, telemetry, or remote note service. The publisher does not receive your browsing history, highlights, notes, tags, saved places, or copied text.

Where this policy applies

This policy covers the StudyNav desktop extension for Chrome, Edge, and compatible Chromium browsers, plus its separate mobile packages for Firefox on Android and Safari on iPhone/iPad. It does not cover JW.org, WOL, Google, Mozilla, Apple, your browser provider, or other services that StudyNav can open.

Data handled on your device

  • Highlights, selected quotations, notes, tags, saved places, and desktop media progress are stored in browser-local storage.
  • Desktop feature settings use the browser extension settings store. If browser sync is enabled, the browser provider may sync those settings under its own privacy policy. Mobile settings and study records use local storage only; StudyNav does not sync them between devices. KikuAI Lab does not receive either set.
  • StudyNav reads the visible structure and text of the JW.org or WOL page you opened so it can place the controls you enabled. This page content is processed in the browser and is not sent to KikuAI Lab.
  • An exported JSON backup is created only when you request it and remains a file under your control.

Requests made after your action

  • In the desktop extension, if you submit a query through “Search JW images with Google,” the query opens in Google Custom Search and is handled under Google's privacy policy.
  • The desktop extension can request an official JW image, audio file, or video file only after you press the related download or clip control. The requested file is processed locally for that action and is not uploaded to KikuAI Lab.
  • The mobile packages do not include Google image search, image/media downloads, audio/video clipping, or player tools.
  • Opening a precise publication link, QR target, or clean publication link navigates to JW.org or WOL. StudyNav does not proxy those requests.

Permissions

  • Storage saves feature settings and the study data you choose to create. Notes, highlights, tags, saved places, and desktop progress remain in browser storage.
  • Access to jw.org, www.jw.org, and wol.jw.org lets StudyNav read the public page you opened and add the controls you enabled. These are the only page origins in the mobile packages.
  • Access to official *.jw-cdn.org media is present only in the desktop extension and is used only for a download or clip you request.
  • Offscreen document is present only in the desktop extension and lets it use browser media APIs to create a local WAV or WebM file while its background worker is running.

The packages contain no remote executable code.

Sharing, retention, and your controls

KikuAI Lab does not sell or share StudyNav user data because it does not collect that data. Local records remain until you delete them, clear the extension's browser storage, or uninstall the extension. You can export a JSON backup, import it into another browser profile, disable individual features, or turn off all StudyNav tools.

Chrome Web Store Limited Use

StudyNav uses page content and user-created study data only to provide the study features described in the extension and its Store listings. It does not transfer that data to the publisher, use it for advertising or credit decisions, sell it, or allow people to read it. The same boundary applies to the separate mobile packages. StudyNav's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes and contact

This page will be updated when StudyNav's data handling changes. Questions or deletion concerns about data stored by the extension can be raised through the public support issue page. Do not include private notes or credentials in a public issue.

Non-affiliation: StudyNav is not produced, maintained, supported, or endorsed by Jehovah's Witnesses. JW.org and JW Library are named only to explain compatibility.
