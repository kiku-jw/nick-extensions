Privacy

StudyNav privacy policy

Effective August 18, 2026. StudyNav is published by KikuAI Lab as an independent, unofficial open-source project.

The short version

StudyNav has no publisher account, analytics, advertising, telemetry, or remote note service. The publisher does not receive your browsing history, highlights, notes, tags, saved places, or copied text.

Where this policy applies

This policy covers the desktop StudyNav extension and the smaller StudyNav Mobile package for Microsoft Edge on Android. It does not cover JW.org, WOL, Google, Microsoft Edge, or other services that StudyNav can open.

Data handled on your device

  • Highlights, selected quotations, notes, tags, saved places, and media progress are stored in browser-local storage.
  • Feature settings use the browser extension settings store. If browser sync is enabled, the browser provider may sync those settings under its own privacy policy. KikuAI Lab does not receive them.
  • StudyNav reads the visible structure and text of the JW.org or WOL page you opened so it can place the controls you enabled. This page content is processed in the browser and is not sent to KikuAI Lab.
  • An exported JSON backup is created only when you request it and remains a file under your control.

Requests made after your action

  • If you submit a query through “Search JW images with Google,” the query opens in Google Custom Search and is handled under Google's privacy policy.
  • The desktop package can request an official JW image, audio file, or video file only after you press the related download or clip control. The Android package does not include media or image downloads.
  • Opening a precise publication link, QR target, or official publication link navigates to JW.org or WOL. StudyNav does not proxy those requests.

Permissions

The Android package requests storage plus access limited to jw.org, www.jw.org, and wol.jw.org. It contains no remote executable code. The desktop package additionally uses an offscreen browser document and official JW media-host access for user-requested local media processing.

Sharing, retention, and your controls

KikuAI Lab does not sell or share StudyNav user data because it does not collect that data. Local records remain until you delete them, clear the extension's browser storage, or uninstall the extension. You can export a JSON backup, import it into another browser profile, disable individual features, or turn off all StudyNav tools.

Changes and contact

This page will be updated when StudyNav's data handling changes. Questions or deletion concerns about data stored by the extension can be raised through the public support issue page. Do not include private notes or credentials in a public issue.

Non-affiliation: StudyNav is not produced, maintained, supported, or endorsed by Jehovah's Witnesses. JW.org and JW Library are named only to explain compatibility.
