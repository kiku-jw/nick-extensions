Privacy

InkShade privacy policy

Effective August 28, 2026. InkShade is published by KikuAI Lab as an independent open-source browser extension.

The short version

InkShade has no account, advertising, analytics, telemetry, remote configuration, or publisher-operated data service. KikuAI Lab does not receive your browsing history, page content, preferences, site list, or custom theme fixes.

Where this policy applies

This policy covers InkShade for Chrome, Edge, Brave, and compatible Chromium browsers. It does not cover the websites you visit, your browser provider, or third-party resources already requested by those websites.

Data processed locally

  • InkShade reads the URL, page structure, CSS, computed colors, and images referenced by page styles so it can render the current page with an adaptive dark theme.
  • This website content is processed in browser memory. It is not sent to KikuAI Lab or an InkShade server.
  • Preferences, automation settings, site rules, and user-authored theme fixes are stored in browser extension storage. Browser synchronization is disabled by default.
  • A settings export is created only when you request it and remains a local file under your control.

Network behavior

InkShade includes no telemetry endpoint, advertising service, analytics service, news feed, premium service, uninstall survey, or remote configuration. To theme a page correctly, it may request stylesheets, fonts, or images already referenced by that page. Those requests go to the website or resource host that supplied the page, not to KikuAI Lab.

Permissions

  • Website access lets InkShade read and transform styles on pages where it is enabled.
  • Storage saves local preferences and site rules.
  • Scripting applies the theme in supported browser contexts.
  • Alarms supports user-configured automation and bounded maintenance work.
  • Font settings applies an optional font choice.
  • Optional context menus add page toggle commands only when enabled by the user.

The extension contains no remote executable code.

Sharing, retention, and your controls

KikuAI Lab does not sell or share InkShade user data because it does not collect that data. Local settings remain until you remove them, clear extension storage, or uninstall InkShade. You can disable InkShade globally or for one site, reset settings, export them, or remove the extension at any time.

Chrome Web Store Limited Use

InkShade uses website content and extension settings only to provide the adaptive dark-theme features described in the extension and its Store listing. It does not transfer this information to the publisher, sell it, use it for advertising or credit decisions, or allow people to read it. InkShade's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Third-party code

The dynamic theme engine is derived from a pinned revision of the MIT-licensed Dark Reader project. The exact revision and license are published in UPSTREAM.json and THIRD_PARTY_NOTICES.txt. InkShade is independently developed and is not affiliated with or endorsed by Dark Reader Ltd.

Changes and contact

This page will be updated when InkShade's data handling changes. Questions can be raised through the public support issue page. Do not include browsing details, credentials, or other private information in a public issue.
