# Comparative research data

`jw-features.json` is a small behavior-only snapshot derived from the public
JW Web Add-on feature guide. It is retained to make the comparison auditable;
it is not the StudyNav feature registry and no third-party source code is
included. StudyNav's current product decision and source links are documented
in [`docs/STUDYNAV-1.4-RESEARCH.md`](../docs/STUDYNAV-1.4-RESEARCH.md).
